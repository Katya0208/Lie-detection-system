# Система распознавания лжи по мимике лица на видеоданных: постановка и решение задачи бинарной классификации.
## Цель:
Разработка и исследование системы анализа физиологических реакций человека по видеозаписи с использованием лицевых лендмарков и методов машинного обучения для детекции реакции на вопрос (с последующей возможностью интерпретации как вероятности правды/лжи).
## Задачи:
1) Провести анализ существующих подходов к детекции лжи и микромимики (MediaPipe, YOLOv8
2) Реализовать модуль детекции лица и извлечения лицевых лендмарков из видео с последующей стабилизацией данных.
3) Построить пайплайн обработки временных рядов координат лендмарков.
4) Разработать и обучить модель для классификации реакции человека (наличие/отсутствие выраженной физиологической реакции).
5) Провести оценку качества модели на тестовой выборке по метрикам бинарной классификации (accuracy, precision, recall, F1).
6) Подготовить архитектуру проекта и репозиторий.
7) Сформулировать рекомендации по дальнейшему расширению системы до мультимодального анализа (видео + аудио).
